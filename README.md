# Discord Bot (ένα αρχείο)

Αρχεία: bot.py, requirements.txt, Procfile, nixpacks.toml, .env.example, .gitignore

## Railway
1. Ανέβασε ΟΛΑ τα αρχεία στο root του GitHub repo.
2. Railway -> Variables -> DISCORD_TOKEN = το token του bot.
3. Discord Developer Portal -> Bot -> ενεργοποίησε SERVER MEMBERS INTENT + MESSAGE CONTENT INTENT -> Save.
4. Δώσε στο bot permission "Manage Server" (για /announce, /sendmessage, invites).
